# HoodX

Black-and-white revolving galaxies, animated binary, and the message **Powered By BunnyHood**. Includes a monochrome **HX** favicon. The visible motion control has been removed; device reduced-motion preferences are still respected.

## Deploy the ZIP

1. Open [Vercel Drop](https://vercel.com/drop) and sign in.
2. Upload **HoodX-Vercel.zip**.
3. Choose your team, enter a project name, and select **Deploy**.

Vercel Drop creates a new project. To update an existing Git-connected project, extract this ZIP into its repository root and commit the files.

## Settings

The included `vercel.json` configures a static site:

- Framework preset: **Other**
- Build command: **empty**
- Output directory: **.**
- No dependencies, API keys, database, or environment variables required.

For a local preview, open `index.html` in your browser.

References: [Vercel Drop documentation](https://vercel.com/docs/drop), [Vercel configuration](https://vercel.com/docs/project-configuration/vercel-json).
